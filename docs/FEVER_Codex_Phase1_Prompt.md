# Codex 실행 프롬프트 — FEVER Phase 1

첨부한 `FEVER_PRD_v1.1.md`를 프로젝트의 단일 제품 요구사항 기준 문서로 읽으세요.

당신은 Next.js App Router, TypeScript, Tailwind CSS, Supabase를 사용하는 시니어 풀스택 개발자입니다. FEVER는 카카오톡 단체방을 보완하는 단일 폐쇄형 소모임 모바일 웹서비스입니다.

## 작업
1. 현재 저장소를 확인하고 Next.js App Router + TypeScript + Tailwind 기반 프로젝트를 초기화하세요. 기존 코드가 있다면 파괴적으로 덮어쓰지 마세요.
2. 모바일 우선 FEVER 공통 레이아웃과 디자인 토큰(딥그린/세이지그린/크림화이트), 헤더, 하단 내비게이션을 구현하세요.
3. PRD의 공개/회원/관리자 라우트에 대한 기본 페이지 및 명확한 플레이스홀더를 구성하세요.
4. Supabase 클라이언트/서버 연결의 안전한 구조와 `.env.example`을 마련하세요. 실제 키가 없으면 연결을 가정하지 마세요.
5. 인증/승인/RLS/관리자 권한을 향후 구현할 위치를 명확히 구분하세요. UI 숨김만으로 보안을 구현하지 마세요.
6. README에 로컬 실행 방법, 필수 환경변수, 남은 작업, 다음 단계 진행 방법을 작성하세요.
7. 가능한 범위에서 lint/typecheck/build를 실행하고 결과를 보고하세요.

## 제한
- **Phase 1만** 구현하세요. 실제 가입·승인·벙 비즈니스 로직은 구현하지 마세요.
- PRD에서 '미확정'으로 표시된 운영 정책을 임의 확정하지 마세요.
- 데이터베이스 키, service role 키, 개인정보를 클라이언트에 노출하지 마세요.
- 외부 서비스에 실제 배포하거나 비용을 발생시키는 작업은 별도 승인 없이 하지 마세요.
