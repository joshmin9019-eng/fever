# Phase 2 정책 확정 및 연결 준비

2026-10-12 사용자가 아래 제안을 승인했습니다. 이 문서는 PRD v1.1의 관련 미확정 항목을 보완합니다.

- 닉네임: 2~20자, 한글 완성형·영문·숫자·밑줄. 공백/특수문자 불허. 영문 대소문자 중복 구분 없음.
- 사진: JPEG/PNG/WebP, 최대 5MB. 리사이즈 정책은 확정하지 않았으며 현재 원본 업로드.
- 출생연도·거주지역 필수. 상세 주소는 수집하지 않음. 2026-10-12 운세 기능 추가 요청에 따라 생일의 월·일은 운세 화면에서 별도 동의를 받고 선택적으로 수집하며, 다른 회원에게 공개하지 않음. 이 최신 결정이 원래의 전체 생년월일 미수집 결정보다 우선함.
- 사용자 요청: 실제 Supabase 연결 없이 코드를 먼저 준비.

기술 흐름은 계정 생성 → 이메일 인증 → 사진·프로필·동의 포함 가입 신청 → 관리자 승인입니다. 사진 없는 계정은 가입 신청이 완료되지 않으며 관리자가 승인할 수 없습니다. 이메일 인증 세션으로 private bucket에 본인 UUID 경로 사진을 업로드하므로 익명 공개 업로드를 허용하지 않습니다. 업로드 후 가입 신청 실패 시 해당 미참조 사진의 삭제를 시도하며, 운영 시 미참조 파일 정리 작업이 필요합니다.

비밀번호의 클라이언트 최소 길이는 8자입니다. Supabase Auth 정책에서도 같은 값 이상을 설정해야 합니다. 이메일 중복 여부는 공개적으로 노출하지 않고 Supabase Auth의 고유 이메일 계정과 일반 안내 메시지를 사용합니다.

닉네임 변경 요청 빈도, 사진 리사이즈 및 벙 관련 미확정 사항은 그대로 남아 있습니다. 가입 동의를 위해 실제 이용약관·개인정보 수집/이용 안내 문서와 버전을 제공해야 합니다. 임시 약관을 실제 약관으로 취급하지 않습니다.

## 2026-10-12 추가 변경

- 사용자 요청으로 별도 이메일 인증 단계를 제거합니다. Supabase Email provider는 켜고 Confirm email을 꺼 신규 계정 세션을 발급합니다. 관리자 승인은 유지합니다.
- 계정 생성 후 가입정보 화면으로 바로 이동하고, 세션이 발급되지 않으면 가입 완료로 간주하지 않습니다.
- 사용자 요청에 따라 기본 이용약관·개인정보 안내와 필수 동의 체크박스를 추가합니다. 운영자 기본 표시는 FEVER 운영팀이며 문의는 기존 모임 운영 채널을 이용합니다.
- 회원 탈퇴 처리 시 개인정보 삭제/비식별화, 법령상 보존 의무 범위 내 분리 보관안을 사용자가 승인했습니다. 구체적인 운영 연락처·국외 처리 관련 추가 고지는 후속 보완이 필요합니다.
- 기존 SQL의 인증시각 검사 및 `pending_email` 상태명은 Supabase 자동 확인 처리와 하위 호환을 위해 유지합니다. 신규 DB migration은 필요하지 않습니다.

## 동의 중복 제거

가입 첫 단계의 두 필수 동의를 기록하고 같은 문서 버전이면 프로필 단계에서 재확인을 요구하지 않습니다. 이전 계정의 동의 기록이 없거나 문서 버전이 변경된 경우에만 동의 입력을 표시합니다. 동의 정보는 본인 신고 정보이며 승인 상태나 관리자 권한과 완전히 분리합니다. 가입 승인 권한은 기존대로 active 관리자/최고관리자에게만 있습니다.
