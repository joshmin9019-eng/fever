# FEVER 프로필·질문 우선 개발 결정

2026-10-12 사용자 요청: 벙 참석은 마지막 단계로 미루고, 나를 소개하고 보여주는 프로필·질문 답변·회원 찾기를 먼저 개발합니다. 참고 화면의 메뉴 구성과 정보 배치를 활용하되 기존 크림·그린 톤을 유지하고 화면을 그대로 복제하지 않습니다.

- 홈의 주요 메뉴는 내 답변 채우기, 대화 발견, 회원 찾기입니다. 본인 프로필은 하단 MY에서 열고 홈에서는 소개 수정으로 바로 연결합니다. 중복 프로필·모임 메뉴는 제거하며 벙 참석은 후속 단계로 둡니다.
- 성별 입력은 선택 사항입니다. 남·여는 회원 카드와 상세 화면에서 다른 색으로 표시하고, 미설정은 중립적으로 표시합니다. 색만으로 구분하지 않도록 글자 배지도 함께 둡니다.
- 질문은 총 50개 안팎으로 운영할 수 있도록 관리자 등록 기능을 제공합니다. 문구가 아직 확정되지 않았으므로 질문을 임의로 채우지 않습니다. 주관식, 단일 선택 객관식, 밸런스게임을 혼합합니다. 객관식 선택지는 2개 이상, 밸런스게임은 2개입니다.
- 관심사 초기 태그 10개는 탐색 시작용으로 제공하며 후속 관리자 운영에서 조정할 수 있습니다.
- 벙 정책은 관리자가 종료 버튼을 누를 때 참석 명단 잠금, 신청 순서대로 수동 승격, 정원 미설정 시 즉시 참석 확정으로 확정되었습니다. 참석 기능 구현은 후속 단계입니다.
- 이상형 취향은 분위기·체형·성향·성격별로 복수 선택하며 승인된 회원에게 공개합니다. 관심 있는 상대 성별은 입력받지 않습니다. 만남 전 서로를 알아보는 분위기를 프로필과 공개 답변 탐색에 반영하되 기존 크림·그린 색상을 유지합니다.
- 관리자 질문 등록 화면에 작성 순서와 주관식·객관식·밸런스게임 선택지 예시를 표시합니다.
